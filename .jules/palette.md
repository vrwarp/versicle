## 2024-07-30 - Added ARIA Labels to Semantic Search History Buttons
**Learning:** Found that custom search history components in `GlobalSemanticSearchView.tsx` used icon-only buttons for deleting and un-starring queries without ARIA labels, creating an accessibility gap for screen readers despite having `title` attributes. Adding `aria-label` along with the visible `title` ensures standard accessibility compliance. We also added descriptive `aria-label` to the text button that triggers the search for screen readers to have action-oriented context rather than just reading the text.
**Action:** When implementing custom interactive lists or pills, ensure icon-only actions have explicit `aria-label` properties, and add action-descriptive labels to the primary actions.
